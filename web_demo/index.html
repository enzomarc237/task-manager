Key Features

🚀

Quick Entry

Natural language processing for instant task creation. Just type "Buy milk today urgent" and watch the magic happen.

🎨

Native Design

Follows macOS Human Interface Guidelines with support for light and dark modes, SF Symbols, and native animations.

⌨️

Keyboard Shortcuts

Full keyboard navigation with customizable shortcuts. Power users can manage tasks without touching the mouse.

📊

Smart Organization

Intelligent categorization with projects, tags, and contexts. Visual priority indicators and progress tracking.

🔔

Native Notifications

Seamless integration with macOS notification center. Never miss a deadline with smart reminders.

♿

Accessibility

Full VoiceOver support, keyboard navigation, and respect for system accessibility preferences.
